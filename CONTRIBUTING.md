# Contributing

Please use the case submission form and link the exact public source. Include the
Kling Image 4.0 mode, exact input order, prompt, matching outputs, and settings
where available. For files you want hosted in the collection, include the license
or permission that covers public display and redistribution.

Edit `data/catalog.json` when contributing repository changes. Run
`node scripts/render.mjs` to regenerate both README indexes and the affected case
pages. Use `node scripts/render.mjs --check` to validate the generated files.
